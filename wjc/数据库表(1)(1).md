### 1. 用户模块

> 来源界面：用户端点击链接进入时后台生成；管理端·答题记录列表「编号」列即本表 dr_id

| 表名                            | 字段名         | 类型         | 说明                                                    |
| ------------------------------- | -------------- | ------------ | ------------------------------------------------------- |
| `visit_record`（匿名访问记录表） | id             | BIGINT       | 主键                                                    |
|                                 | dr_id          | VARCHAR(32)  | 匿名编号，顺序签发如DR-2026-000017，对外展示（每次点击链接签发） |
|                                 | share_link_id  | BIGINT       | 关联访问链接ID（video_share_link）                      |
|                                 | entered_at     | DATETIME     | 进入时间                                                |
|                                 | created_at     | DATETIME     | 创建时间                                                |

**说明（G2 匿名化）：不采集 openid/姓名/手机号/职称/地区等任何个人信息；每次点击链接进入均生成一条访问记录，一条记录即代表一次匿名访问并顺序签发一个 dr_id；dr_id 仅为顺序编号，无法回溯个人身份。**

## 附：建设目标对照（依据V1.1(1)）

| 方案目标 | 说明 | 支撑表 |
| --- | --- | --- |
| G1 学习闭环 | 前测3题→视频/图文→后测3题全流程 | `video_question`、`exam_record`、`exam_answer` |
| G2 匿名身份 | 不注册不登记、不采集姓名/手机号/openid 等任何信息；每次点击链接生成访问记录并签发顺序编号对外展示 | `visit_record`、`exam_record` |
| G4 上架低门槛 | Excel一次导入课程+视频+图文+前测3+后测3 | `import_task`（R8标准模板6张表） |
| G5 数据资产 | 完成率/通过率/题目正确率统计，一键导出（机构维度随链接归属机构统计） | `organization`、`video_share_link`、`exam_record`、`exam_answer` |
| G6 安全合规 | 个人信息最小必要、内容不承诺疗效 | `visit_record`（无openid及任何个人信息）、`operation_log` |
| R2 匿名编号 | 顺序签发DR-2026-XXXXXX对外展示，每次点击链接独立签发 | `visit_record.dr_id`、`exam_record.dr_id`（快照） |
| R5 重答 | 默认60分及格，未通过可重答 | `exam_record.attempt_no`、`system_config.pass_score` |
| R6 断点续传 | 分片上传、自动转码、自动生成封面 | `video.oss_upload_id`、`transcode_status`、`cover_url` |
| R9 资源 | 服务器+OSS（资源清单，非库表） | OSS路径字段：`video.oss_path`、`question.image_url` |
| 3.2-5 视频链接 | 生成用户访问链接，可选时效性 | `video_share_link` |
| 设计原则·内容与配置分离 | 课程—内容—题目三级关联 | `topic`（课程）→`video`（内容）→`question`（题目） |
| 预留扩展 | 证书、多专题 | `certificate`、`topic` |
