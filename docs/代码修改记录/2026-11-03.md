这些改动只在本地开发生效。生产构建不会加载假数据。

## 假数据覆盖的流程

1. 用户端首页列出两条已上架内容。
2. 「胸口闷、头晕，先分清这两件事」带本地视频 `/videos/demo.mp4`，五道题。观看进度达到 1% 即可进入看完答题。
3. 「药不能跟着别人吃」没有视频，看完文字要点即可答题。
4. 学前提交后进入观看页；看完提交后进入结果页。结果按真实选择判分，60 分通过。
5. 同一条答题会写入管理端答题记录和数据统计。
6. 管理端视频、用户、分类、题目、分享链接、登录接口也返回假数据，列表上的新增、编辑、上下架会留在当前标签页。

## 如何恢复真实后端

1. 打开 `src/router/index.js`，取消 `beforeEach` 和文件顶部两处注释。
2. 在 `.env.development` 把 `VITE_USE_MOCK` 改成 `false`，或删除这一行并在启动前设置 `VITE_USE_MOCK=false`。
3. 重新执行 `npm run dev`。假数据开关在 Vite 启动时写入，改环境变量后必须重启。
4. 浏览器里可以清掉 `sessionStorage` 的 `pv.mock.backend`，避免旧的假进度还在。

路由守卫注释不依赖环境变量。只关假数据、不恢复守卫时，页面仍会放行，但接口会重新请求后端。
