# 代码修改记录

依据《开发手册》四、1.1「代码修改记录规范」：

1. 所有代码修改必须记录，任何代码变更都同步记录至本目录。
2. 文件命名：`YYYY-MM-DD.md`（如 `2026-10-20.md`），自动获取当前日期作为文件名。
3. 一次询问对应一次记录：用户的一次需求对应一份修改记录，不得拆分多个文档。
4. 内容规范：必须记录**新增代码记录**与**删除代码记录**，且**先记录删除范围，再记录新增范围**。

## 记录模板

````markdown
# 2026-10-20 代码修改记录

## 需求描述

（一句话说明本次需求）

## 删除范围

- 文件：`src/views/...`
- 内容：删除了什么代码/逻辑

## 新增范围

- 文件：`src/views/...`
- 内容：新增/修改了什么代码/逻辑
````
