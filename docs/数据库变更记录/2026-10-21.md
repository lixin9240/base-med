# 2026-10-21 数据库变更记录

## 变更：video_progress 进度精度提升（0.1% 粒度）

- **迁移文件**：`Backend/database/migrations/2026_10_21_000002_change_video_progress_precision.php`
- **内容**：
  - `watched_seconds` INT → `DECIMAL(9,2)`（秒数保留 2 位小数）
  - `progress_percent` TINYINT UNSIGNED → `DECIMAL(5,1)`（百分比精确到 0.1%）
- **原因**：观看进度原来按整数百分比存储，短视频粒度过粗（10 秒视频只能 10% 一跳）；改为小数后支持 0.1% 粒度
- **兼容性**：列加宽不影响现有数据与读取；解锁阈值 90 的比较逻辑不变
- **执行**：已在共享库（47.114.49.68/base-med）执行完毕；队友拉取代码后需 `php artisan migrate`
- **回滚**：`php artisan migrate:rollback`（恢复 INT / TINYINT）
