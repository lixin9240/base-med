# 数据库变更记录

依据《开发手册》一、2.3「数据库变更管理」与四、1.1「数据库修改记录规范」：

1. 数据库发生任何变更（新增/删除表、新增/删除/修改字段、修改类型/长度、新增/删除索引、约束、数据迁移）必须同步记录至本目录。
2. 文件命名：**以表名作为文件名**，如 `users.md`、`video.md`；一张表一个文件，多次变更在文件内追加记录。
3. 每条变更必须标明以下类型之一：字段添加、字段修改、字段删除、表删除。
4. 必须记录 SQL 语句。
5. 日期格式：`YYYY-MM-DD HH:mm:ss`。
6. 修改人必须读取 `git config user.name`。
7. 所有变更脚本纳入版本管理，确保可追溯、可回滚；禁止直接在生产环境手工修改而不留记录。

## 记录模板

````markdown
# users 表变更记录

## 2026-10-20 15:30:00 · 字段添加

- 修改人：（git config user.name）
- 变更原因：xxx
- 影响范围：xxx
- 回滚方案：xxx

```sql
ALTER TABLE users ADD COLUMN nickname VARCHAR(64) NULL AFTER name;
```
````
