# 接口文档（conclusion）

依据《开发手册》三、3.2「接口文档归类规范」，接口文档统一存放在本目录，分为两类：

## 1. 总结接口文档（模块级全量文档）

- 用于记录**某个模块的全部接口信息**，属于系统级归档文档。
- 必须包含该模块所有接口，统一字段结构：接口路径、请求方式、请求参数、请求参数类型、是否必须传入、返回参数、返回参数类型、备注。
- **注意：该文档不能由 AI 修改，统一手动新增或复制维护。**

## 2. 前端对接接口文档（交付文档）

### 2.1 接口总对接文档（全量）

- 用于前端完整对接某模块所有接口。
- 必须包含该模块**所有接口完整信息**（路径、请求方式、请求参数、参数类型、是否必须传入、返回参数、返回参数类型）。
- 强调"完整性"，用于首次对接或整体联调，不包含变更说明。

### 2.2 接口修改文档（增量）

- 用于记录接口变更内容：新增字段、删除字段、修改字段类型、返回结构变化、业务逻辑调整。
- 备注必须说明变更内容；前端可快速定位变更。
- **注意：生成修改文档时必须同步更新接口总文档。**
