## 一、平台总览

本平台面向两个用户群体，天然分成两套前端：

| 端 | 目标用户 | 入口 | 路由前缀 |
| --- | --- | --- | --- |
| 管理员端 | 运营 / 内容管理员 | `/admin/login` | `/admin/*` |
| 移动端 | 基层 DR 医生 | `/mobile/home` | `/mobile/*` |

管理员端负责视频上传、题目配置、答题记录查看和数据统计；移动端负责医生看视频、答题、巩固和查看自己的学习报告。两端共享同一个后端接口（统一走 `http://47.114.49.68:7462/api`），前端通过 Vite 开发代理转发，后端按 URL 前缀（`/api/admin/*` vs `/api/public/*`）区分管理员接口和公开接口。

数据链路：前端页面 → `src/api/*` 封装层 → `src/api/http.js` 统一处理（JWT 注入、401 自动跳转登录）→ 后端接口。管理员端额外有 `router.beforeEach` 守卫强制登录。

## 二、管理员端

管理员端整体由 `AdminLayout.vue` 承载，左侧 `AdminSidebar.vue` 提供导航，右侧为各子页面。侧边栏目前有四个菜单项：视频管理、答题记录、数据统计、管理员账号。后端还提供了分类管理、操作日志、导入任务历史三个接口模块，但前端尚未建对应页面。

### 2.1 登录与身份认证

**入口页面**：`/admin/login` → `Login.vue`；`/admin/forget-password` → `ForgetPassword.vue`

**子功能**：

#### 2.1.1 管理员登录

- 表单字段：用户名、密码
- 登录成功后，后端返回 JWT token 和管理员信息，前端写入 `localStorage`（`saveAdminAuth`），跳转至 `/admin/videos`；如果 URL 带了 `?redirect=` 参数（路由守卫拼的），则跳回原目标页
- 登录失败提示后端返回的 `msg`（如"账号或密码错误"、"账号已被禁用"）
- 接口：`POST /api/admin/auth/login`

#### 2.1.2 登录守卫

- 全局路由守卫在每次跳转时检查 `localStorage` 里的 token
- 白名单（登录页、忘记密码页）放行；已登录访问登录页自动跳到首页
- 非白名单页无 token → 强制跳登录，并把当前目标路径以 `redirect` 参数挂上
- 任意接口返回 HTTP 401，`http.js` 自动清 token 并跳登录（防 token 过期后每页报红）

#### 2.1.3 登出

- 侧边栏底部"退出登录"按钮触发
- 调用 `POST /api/admin/auth/logout` 通知后端让 token 失效，然后清本地存储并跳登录页

#### 2.1.4 忘记密码 / 重置密码（前端已接 API 但未建页面）

- `src/api/auth.js` 已封装：`POST /api/admin/auth/forgot-password`（发验证码）、`POST /api/admin/auth/reset-password`（验证码 + 新密码）
- `ForgetPassword.vue` 已存在，但入口尚未在侧边栏暴露

### 2.2 视频管理

**页面**：`VideoList.vue`，组件位于 `components/admin/videos/`

这是管理员端最核心的模块，承载视频全生命周期管理和题目配置。

#### 2.2.1 视频列表

- 列：封面缩略图、视频标题、分类、时长、状态（上架/下架带颜色状态点）、答题人数、正确率、创建时间、操作
- 顶部筛选：关键词搜索（标题/文件名）、分类下拉、状态下拉（全部/已上架/已下架）
- 分页：每页 20/50/100 条切换，服务端分页
- 接口：`GET /api/admin/video/list`（带 `keyword`、`category_id`、`status`、`page`、`page_size`）

#### 2.2.2 新增 / 编辑视频

- 共用 `VideoFormModal.vue` 弹窗
- 字段：视频标题、分类下拉（从分类接口取选项）、简介、本地视频文件选择
- 新增时：先调 `POST /api/admin/video/create` 拿到 `video_id` → 调 `POST /api/admin/video/upload/init` 建立上传任务 → 分片传输（文档未定义分片端点，暂为占位）→ 调 `POST /api/admin/video/upload/complete` 通知后端合并并触发转码
- 编辑时：回填现有信息，重传文件则走同样的 init → complete 链路，不重传只改元数据则调 `POST /api/admin/video/update`
- 转码是后端异步完成的，转码完成后封面、时长会自动回填到视频记录

#### 2.2.3 上架 / 下架

- 列表每行状态列是一个开关，点击即切换
- 调 `POST /api/admin/video/update-status`，参数 `{ id, status }`（0 下架 / 1 上架）
- 成功后本地立即更新开关状态；失败自动回退并提示错误
- 防重复点击：切换期间开关置灰

#### 2.2.4 删除视频

- 点"删除"弹出二次确认弹窗 `VideoDeleteModal.vue`
- 确认后调 `POST /api/admin/video/delete`（软删除），后端前置校验：已有答题记录的视频不允许删除
- 删除成功后刷新列表

#### 2.2.5 视频题目配置

- 列表"配置题目"按钮打开 `QuestionConfigDrawer.vue`（右侧抽屉）
- 抽屉内可以：新增题目、编辑题目、删除题目、调整题目顺序
- 每题字段：题干、题型（单选/多选/判断）、选项文本、正确答案、解析
- 支持批量导入：`QuestionImportModal.vue` 提供模板下载（Excel）+ 文件上传 → 后端返回 `task_id` → 轮询 `GET /api/admin/import/task-detail` 看导入进度 → 完成后调 `POST /api/admin/import/confirm` 确认入库
- 题目在视频下再分两个阶段：前测题（看视频前答）和看课答题（看完视频后答），由 `stage` 字段区分

#### 2.2.6 分享链接

- `VideoShareLinkModal.vue`：为视频生成独立的分享链接，链接里带 `video_id`，医生通过这个链接进入移动端直接锁定该视频
- 可临时失效（禁用链接）或撤销
- 接口：`POST /api/admin/video/share-link/generate`、`POST /api/admin/video/share-link/revoke`

### 2.3 题目管理

题目作为视频的子资源存在，没有独立列表页。接口已全部封装在 `src/api/question/index.js`：

- `GET /api/admin/question/list` — 按视频取题目
- `POST /api/admin/question/create` — 新增单题
- `POST /api/admin/question/update` — 编辑单题
- `POST /api/admin/question/delete` — 删除单题
- `POST /api/admin/question/batch-sort` — 批量调整顺序
- `POST /api/admin/question/batch-import` — 批量导入（返回 task_id）
- `GET /api/admin/import/task-detail` + `POST /api/admin/import/confirm` — 导入链路闭环

### 2.5 答题记录管理

**页面**：`Records.vue`

#### 2.5.1 记录列表

- 列：提交时间、视频名称、医生编号（dr_id）、前测正确率、看课答题正确率、总体正确率、结果（通过/未通过）
- 筛选：视频下拉（从视频列表接口取）、结果下拉（通过/未通过）
- 分页：服务端分页
- 接口：`GET /api/admin/exam-record/list`

#### 2.5.2 作答详情

- 点列表行"查看作答"打开详情弹窗
- 头部：医生编号、视频名、提交时间、前测/看课答题汇总、结果徽标
- 逐题卡片：按阶段（前测 / 看课答题）分组，答对题只显示正确答案，答错题额外显示用户选择并标红；左侧色条绿/红区分对错
- 接口：`GET /api/admin/exam-record/detail?exam_record_id=xxx`

#### 2.5.3 导出

- "导出"按钮带当前筛选条件（视频 + 结果）调用后端导出，返回 `{ filename, url }`，前端直接打开后端返回的签名下载地址（xlsx，7 天有效）
- 接口：`GET /api/admin/exam-record/export`

### 2.6 数据统计

**页面**：`Stats.vue`

页面挂载时并行请求三个统计接口，任一失败显示统一错误条。

#### 2.6.1 统计大盘（顶部卡片）

- 视频总数、已上架视频数、答题总次数、平均正确率、整体通过率
- 接口：`GET /api/admin/statistics/overview`

#### 2.6.2 各视频答题情况（表格）

- 每行一个视频：视频名、状态（上架/下架）、答题次数、前测平均正确率、看课答题平均正确率、整体通过率
- 正确率和通过率带进度条显示百分比
- 接口：`GET /api/admin/statistics/video-list`

#### 2.6.3 最容易答错的题

- 表格列出错误率最高的 N 道题：所属视频、阶段（前测/看课答题）、题型、题干摘要、错误率
- 后端已按错误率降序排好
- 接口：`GET /api/admin/statistics/wrong-question`

#### 2.6.4 导出统计

- "导出统计"按钮调后端生成 Excel，直接下载
- 接口：`GET /api/admin/statistics/export`

### 2.7 管理员账号管理

**页面**：`UserList.vue`，组件：`UserFormModal.vue`、`UserDeleteModal.vue`

#### 2.7.1 账号列表

- 列：用户名（登录账号）、姓名、邮箱、角色（admin）、状态（正常/已禁用）、最后登录时间
- 筛选：关键词搜索（用户名/姓名）、状态下拉（全部/正常/已禁用）
- 分页：服务端分页
- 接口：`GET /api/admin/admin-user/list`（带可选 `keyword`、`status`）

#### 2.7.2 新增账号

- 点"新增用户"打开表单弹窗
- 字段：用户名（登录账号，唯一）、密码（6~32 位，必填）、姓名、邮箱、角色（admin）、状态（正常/已禁用）
- 前端校验通过后调 `POST /api/admin/admin-user/create`，返回新账号的 id

#### 2.7.3 编辑账号

- 列表行"编辑"打开同一表单弹窗，回填现有信息
- 密码字段留空则后端不重置密码；填写则覆盖
- 接口：`POST /api/admin/admin-user/update`

#### 2.7.4 禁用 / 恢复

- 列表行"禁用登录 / 恢复登录"按钮，点击即切换
- 实现上调用 update 只传 `{ id, status }`（后端尚未部署独立的 `update-status` 路由，等部署后可切）
- 切换期间按钮置灰防重复

#### 2.7.5 删除账号

- 点"删除"弹出二次确认弹窗
- 后端前置校验：不能删除当前登录的账号，校验不通过直接报错给弹窗
- 接口：`POST /api/admin/admin-user/delete`（软删除）

## 三、移动端（基层医生端）

移动端由 `MobileLayout.vue` 承载，底部四个 Tab：首页、学习、巩固、我的（学习报告）。所有公开接口走 `/api/public/*` 前缀，不经过 JWT 守卫（由分享链接里的 `video_id` 锁定学习内容）。

### 3.1 首页

**页面**：`Home.vue`

#### 3.1.1 视频列表

- 医生进入分享链接后直接锁定目标视频，首页即为该视频的入口
- 显示视频封面、标题、时长、学习进度百分比
- 接口：`GET /api/public/video-detail?video_id=xxx`（带进度、前测状态）

#### 3.1.2 学习状态提示

- 如果前测已答过 → 显示"继续观看"
- 如果前测未答 → 显示"开始学习"并提示先完成前测

---

### 3.2 视频学习页

**页面**：`Learn.vue`

#### 3.2.1 视频播放

- 内嵌视频播放器，播放由后端返回的视频地址（已过 CDN 签名）
- 播放进度实时上报：每 5% 或播放完触发一次上报，后端记录 `progress` 百分比
- 接口：`POST /api/public/progress-report`

#### 3.2.2 前测入口

- 如果视频配置了前测题，视频下方显示"开始前测"按钮
- 点击进入答题页（`stage=pretest`）

#### 3.2.3 看课答题入口

- 视频播放完毕（进度 ≥ 95%）后，显示"开始答题"按钮
- 点击进入答题页（`stage=posttest`）

---

### 3.3 答题页

**页面**：`Quiz.vue`，组件：`QuizPanel.vue`

#### 3.3.1 题目展示

- 顶部显示当前阶段（前测 / 看课答题）和进度条
- 逐题展示：题干、题型标签（单选/多选/判断）、选项列表
- 单选题点选即锁定；多选题支持多选；判断题点"正确/错误"

#### 3.3.2 答题提交

- 全部答完后点"提交"，前端收集所有题目的用户选择调 `POST /api/public/submit-quiz`
- 后端逐题比对正确答案，计算正确率，返回答题结果（通过/未通过、每题对错、正确答案）
- 提交后不可修改

#### 3.3.3 结果反馈

- 提交后直接在答题页显示结果汇总：总题数、答对题数、正确率、是否通过
- 每题显示对错标记和正确答案（用户选择与正确答案不同时高亮）
- 答错的题自动收集到错题本（后端标记，巩固页读取）

---

### 3.4 错题巩固页

**页面**：`Consolidate.vue`

#### 3.4.1 错题列表

- 从后端取当前医生在所有视频中答错的题
- 按视频分组展示：视频名 → 该视频下的错题列表
- 每题可展开查看：题干、用户当时的选择、正确答案、解析
- 接口：`GET /api/public/wrong-questions`

#### 3.4.2 重做错题

- 支持单题重做或整组重做，重做不计入新的答题记录，只更新错题本状态（答对了从错题本移除）

---

### 3.5 学习报告页

**页面**：`Report.vue`

#### 3.5.1 个人汇总

- 医生编号、姓名
- 已学视频数、答题总次数、总正确率、总通过率
- 接口：`GET /api/public/exam-result`

#### 3.5.2 各视频学习明细

- 每个视频一行：视频名、前测正确率、看课答题正确率、是否通过
- 点视频可跳回该视频首页，继续学习或查看答题记录
