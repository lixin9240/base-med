# docs

项目文档目录，结构依据《开发手册》维护：

| 目录 | 用途 | 维护规则 |
| --- | --- | --- |
| `conclusion/` | 接口文档（总结接口文档 + 前端对接接口文档） | 接口新增/修改/删除后必须同步更新，并及时通知前端 |
| `代码修改记录/` | 代码变更记录 | 一次需求一份，文件名 `YYYY-MM-DD.md`，先记删除范围再记新增范围 |
| `数据库变更记录/` | 数据库结构变更记录 | 以表名命名文件（如 `users.md`），必须记录 SQL、类型、日期、修改人 |
| `agents/` | AI 协作配置（issue tracker、triage labels、domain docs） | 见各文件说明 |
