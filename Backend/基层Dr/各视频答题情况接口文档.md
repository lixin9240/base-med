# 基层医生DR平台 · 各视频答题情况接口文档

> 本文档描述「数据统计」模块的**各视频答题情况**接口（对应主接口文档 2.6.2），供前端对接使用。

---

# 1 接口概览

- 路径：`GET /api/admin/statistics/video-list`
- Method：GET
- 鉴权：需在请求头携带 `Authorization: Bearer {token}`（管理后台接口，`auth:admin`）
- 无查询参数
- 返回：统一响应信封，业务数据在 `data` 字段中（**全量数组**，页面无分页 / 筛选，由前端整体渲染）

## 1.1 响应信封

```json
{
  "code": 0,
  "msg": "获取成功",
  "data": [ { "...": "见下方字段说明" } ],
  "success": true,
  "trace_id": "abc123..."
}
```

> `code=0` 表示成功；前端以 `data` 为数组直接渲染列表。

---

# 2 业务语义

- 返回**全部视频**各一条（含未上架、无人答题的视频）；
- 排序：按 `sort_order` 升序，相同再按 `id` 升序；
- 答题相关指标来自 `exam_record` 按 `video_id` 聚合，**无人答题的视频对应指标为 null / 0**（见字段说明）。

---

# 3 响应字段

`data` 为对象数组，每条记录字段如下：

| 字段              | 类型     | 说明                                                         |
| ----------------- | -------- | ------------------------------------------------------------ |
| video_id          | int      | 视频 id                                                      |
| title             | string   | 视频标题（「视频」列）                                       |
| category_name     | string/null | 分类名（「分类」标签，标题旁展示），未分类为 null         |
| status            | int      | 状态：`1` 已上架（绿点）/ `0` 已下架（灰点）                 |
| answer_times      | int      | 答题次数（exam_record 计数）；无人答题为 `0`                  |
| avg_accuracy      | int/null | 「平均正确率」兼容字段，**历史口径 = post_avg_accuracy**；无人答题为 null，前端显示「—」 |
| pre_avg_accuracy  | int/null | 答题前（前测）平均正确率，百分比四舍五入；无人答题为 null     |
| post_avg_accuracy | int/null | 答题后（后测）平均正确率，百分比四舍五入；无人答题为 null     |
| pass_rate         | int/null | 通过率 = 通过记录数 / 答题记录总数 × 100（四舍五入）；无人答题为 null，前端附进度条（颜色按高低区分） |

> `avg_accuracy` 为兼容字段，仅用于「平均正确率」单列展示；新版「答题前 / 答题后正确率」两列请分别使用 `pre_avg_accuracy` / `post_avg_accuracy`。

---

# 4 示例

```json
{
  "code": 0,
  "msg": "获取成功",
  "success": true,
  "trace_id": "t-001",
  "data": [
    {
      "video_id": 1,
      "title": "心肺复苏基础操作",
      "category_name": "急救技能",
      "status": 1,
      "answer_times": 12,
      "avg_accuracy": 67,
      "pre_avg_accuracy": 64,
      "post_avg_accuracy": 67,
      "pass_rate": 75
    },
    {
      "video_id": 4,
      "title": "儿童疫苗接种后不良反应识别",
      "category_name": "妇幼保健",
      "status": 0,
      "answer_times": 0,
      "avg_accuracy": null,
      "pre_avg_accuracy": null,
      "post_avg_accuracy": null,
      "pass_rate": null
    }
  ]
}
```

> 第二条为「已下架且无人答题」的视频：`answer_times=0`，其余正确率 / 通过率字段为 `null`，前端对应显示「—」。

---

# 5 前端渲染建议

对应页面「各视频答题情况」表格列：视频（含分类标签）/ 状态 / 答题次数 / 答题前正确率 / 答题后正确率 / 通过率。

| 列               | 取值                                                        |
| ---------------- | ----------------------------------------------------------- |
| 视频（+分类标签） | `title` + `category_name`                                   |
| 状态             | `status === 1` → 已上架（绿点），否则已下架（灰点）          |
| 答题次数         | `answer_times`                                              |
| 答题前正确率     | `pre_avg_accuracy`（null → 「—」）                           |
| 答题后正确率     | `post_avg_accuracy`（null → 「—」）                          |
| 通过率           | `pass_rate`（null → 「—」，可附进度条）                      |

> ⚠️ **字段名提醒**：后端返回的是 `pre_avg_accuracy` / `post_avg_accuracy`，不是 `pretest_accuracy` / `posttest_accuracy`。前端如按 `pretest_accuracy` / `posttest_accuracy` 取值会恒为 undefined，导致答题前 / 答题后正确率两列始终显示「—」。

---

# 6 失败场景

| 场景                | HTTP | 说明                                              |
| ------------------- | ---- | ------------------------------------------------- |
| 未登录 / token 失效 | 401  | 前端清 token 跳登录                               |
| 无任何视频数据      | 200  | `data` 为空数组 `[]`，前端显示空态                 |
| 服务器 / 数据库异常 | 500  | body `code` 对应 90000（系统）/ 60000（数据库）段 |
