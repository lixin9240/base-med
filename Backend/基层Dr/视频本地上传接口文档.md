# 基层医生DR平台 · 视频本地上传接口文档

> 本文档描述「视频管理」**本地上传（source_type=2）**相关接口，供前端对接。
> 涉及：初始化视频上传（2.3.7）、分片上传、完成视频上传（2.3.8）、封面图上传（2.3.9）。

---

# 1 上传流程概览

```
① 新增/编辑视频（source_type=2，可不传 video_url）
        ↓
② 初始化视频上传（2.3.7）  → 拿到 oss_upload_id / oss_path / part_size / parts
        ↓
③ 分片上传（前端 SDK 直传 OSS；本地模拟走 upload/chunk）
        ↓
④ 完成视频上传（2.3.8）   → 合并分片 + 上传 OSS + 触发转码，返回视频 OSS 地址 video_url
        ↓
⑤（可选）上传封面图片（2.3.9） → 返回封面 OSS 地址，填入 cover_url
```

---

# 2 通用说明

- 数据格式：请求与响应均为 `application/json`（分片上传、封面图上传为 `multipart/form-data`）。
- 统一响应结构：

```json
{ "code": 0, "msg": "success", "data": {} }
```

- 本模块为**管理后台**接口，均需在请求头携带 `Authorization: Bearer {token}`。
- 下文「返回示例」仅展示 `data` 部分。

## 2.1 通用错误码

| HTTP 状态码 | 说明 |
| ----------- | ---- |
| 400 | 业务错误（body `code` 为 40000 段） |
| 401 | 未登录 / token 失效 |
| 404 | 资源不存在（视频不存在、分片不存在） |
| 422 | 参数错误 / 参数校验不通过 |
| 500 | 服务器错误 |
| 502 | 第三方服务异常（OSS 上传失败，body `code` 为 50000 段） |

---

# 3 接口

## 3.1 初始化视频上传（2.3.7）

- 路径：`POST /api/admin/video/upload/init`
- Method：POST
- 说明：初始化 OSS 分片上传任务；若该视频存在未完成的上传任务（`oss_upload_id` 已存在且未完成），直接返回原 `oss_upload_id`，实现断点续传。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| file_name | string | 是 | 原始文件名（≤ 255 字） |
| file_size | bigint | 是 | 文件大小（字节，≥ 1） |
| video_id | bigint | 否 | 已创建视频的 id（编辑时重新上传场景） |

### 返回示例

```json
{
    "code": 0,
    "msg": "上传任务已初始化",
    "data": {
        "oss_upload_id": "upload_abc123",
        "oss_path": "video/2026/10/upload_abc123_xxx.mp4",
        "part_size": 1048576,
        "parts": 10
    }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| oss_upload_id | string | 上传任务 ID（后续分片 / 完成上传时回传） |
| oss_path | string | OSS 对象存储路径（object key，非访问地址） |
| part_size | int | 每个分片大小（字节，默认 1MB） |
| parts | int | 分片总数 = ceil(file_size / part_size) |

### 失败场景

- `file_name` 缺失 / 超长 → 422「原始文件名不能为空 / 文件名不能超过255字」
- `file_size` 缺失 / 非整数 / <1 → 422「文件大小不能为空 / 必须为整数 / 不合法」
- `video_id` 非整数 / <1 → 422「视频ID必须为整数 / 不合法」
- `video_id` 对应的视频不存在 → 404「视频不存在」

## 3.2 上传分片（本地模拟辅助）

- 路径：`POST /api/admin/video/upload/chunk`
- Method：POST（`multipart/form-data`）
- 说明：**本地模拟辅助接口**。真实环境使用 OSS 直传时，分片由前端 SDK 直传 OSS，可跳过本接口。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| oss_upload_id | string | 是 | 上传任务 ID（≤ 128 字） |
| part_number | int | 是 | 分片序号（从 1 开始） |
| file | file | 是 | 单个分片文件 |

### 返回示例

```json
{ "code": 0, "msg": "分片上传成功", "data": { "success": true } }
```

## 3.3 完成视频上传（2.3.8，返回 OSS 地址）

- 路径：`POST /api/admin/video/upload/complete`
- Method：POST
- 说明：合并全部分片 → 上传 OSS → 触发转码，并**返回视频上传到 OSS 的访问地址**。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| oss_upload_id | string | 是 | 上传任务 ID（≤ 128 字） |
| video_id | bigint | 是 | 关联视频 id（≥ 1） |

### 返回示例

```json
{
    "code": 0,
    "msg": "上传完成",
    "data": {
        "video_id": 1,
        "video_url": "https://oss.example.com/video/2026/10/upload_abc123_xxx.mp4",
        "transcode_status": 2
    }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| video_id | bigint | 视频 ID |
| **video_url** | string | **视频上传到 OSS 后的访问地址**（即 `video.video_url`，正式环境为 OSS 直链） |
| transcode_status | tinyint | 转码状态：0 待转码 1 转码中 2 已完成 3 失败 |

> 说明：转码为异步过程，`transcode_status` 实时状态以 2.3.1 列表 / 2.3.2 详情为准；`video_url` 为合并上传后的最终视频地址，可直接用于播放。

### 失败场景

- `oss_upload_id` 缺失 / 超长 → 422「上传任务ID不能为空 / 不能超过128字」
- `video_id` 缺失 / 非整数 / <1 → 422「视频ID不能为空 / 必须为整数 / 不合法」
- 视频不存在 → 404「视频不存在」
- 上传分片不存在 → 502「上传分片不存在，请重新上传」
- OSS 上传失败 → 502（body `code` 为 50000 段）

## 3.4 上传封面图片（2.3.9）

- 路径：`POST /api/admin/video/upload/cover`
- Method：POST（`multipart/form-data`）

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| file | file | 是 | 图片，支持 jpg / jpeg / png / webp / gif，≤ 2MB |

### 返回示例

```json
{
    "code": 0,
    "msg": "封面上传成功",
    "data": {
        "url": "https://oss.example.com/cover/2026/10/20261023_143000_a1b2c3d4.jpg"
    }
}
```

> 说明：返回的 `url` 为封面 OSS 地址；新增 / 编辑视频时填入 `cover_url`（管理端列表与用户端共用同一封面）。

---

# 4 数据表说明

| 表 | 用途 |
| ---- | ---- |
| `video` | 初始化写入 `oss_upload_id` / `oss_path`；完成上传回填 `video_url` / `oss_path` / `file_size` / `transcode_status` |
| 无其他表 | 分片临时文件存于 OSS `video/parts/{oss_upload_id}/`，完成后清理 |
