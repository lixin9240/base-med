# 基层医生DR平台 · 视频封面图接口文档

> 管理端与用户端共用**同一张封面图**（`video.cover_url`），不新增独立字段。
> 本文档描述「视频管理」列表新增返回的 `cover_url` 字段，以及封面上传接口。

---

# 1 背景与字段说明

- 管理端「视频管理」列表缩略图 与 用户端首页/详情封面，使用**同一个字段** `cover_url`。
- 上传一次封面，两端共用；未上传封面时，管理端列表显示占位图标，用户端以分类图标占位。

### 本次变更

视频列表接口（2.2.1）**新增返回 `cover_url` 字段**，供列表缩略图展示（此前列表未返回封面，缩略图恒为占位图标）。

---

# 2 通用说明

- 数据格式：请求与响应均为 `application/json`（上传接口为 `multipart/form-data`）。
- 统一响应结构：

```json
{ "code": 0, "msg": "success", "data": {} }
```

- 本模块为**管理后台**接口，均需在请求头携带 `Authorization: Bearer {token}`。

## 2.1 通用错误码

| HTTP 状态码 | 说明 |
| ----------- | ---- |
| 400 | 业务错误（body `code` 为 40000 段） |
| 401 | 未登录 / token 失效 |
| 404 | 资源不存在（视频不存在、分类不存在） |
| 422 | 参数错误 / 参数校验不通过 |
| 502 | 第三方服务异常（OSS 上传失败） |

---

# 3 封面上传接口（复用）

- 路径：`POST /api/admin/video/upload/cover`
- Method：POST（`multipart/form-data`）

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| file | file | 是 | 图片文件，仅支持 jpg / jpeg / png / webp / gif，大小 ≤ 2MB |

### 返回示例

```json
{
    "code": 0,
    "msg": "封面上传成功",
    "data": {
        "url": "https://oss.example.com/cover/2026/10/20261023_143000_a1b2c3d4.jpg"
    }
}
```

> 说明：返回的 `url` 为封面 OSS 地址，前端拿到后填入 `cover_url`，随视频新增/编辑提交即可。

---

# 4 视频管理接口变更

> 仅「视频列表」新增了 `cover_url` 返回；详情/新增/编辑本就支持 `cover_url`，无变化。

## 4.1 视频列表（2.2.1，新增返回字段）

- 路径：`GET /api/admin/video/list`
- 变更：列表每条记录新增 `cover_url` 字段，供列表缩略图展示。

### 返回示例（单条，仅展示关键字段）

```json
{
    "code": 0,
    "msg": "获取成功",
    "data": {
        "list": [
            {
                "id": 5,
                "title": "心肺复苏基础操作",
                "category_name": "急救技能",
                "cover_url": "https://oss.example.com/cover/2026/10/xxx.jpg",
                "speaker": "郭军",
                "speaker_title": "主任医师",
                "status": 1
            }
        ],
        "total": 1,
        "page": 1,
        "page_size": 20
    }
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| cover_url | string | 封面图地址，可空；为空时前端显示占位图标 |

## 4.2 视频详情 / 新增 / 编辑（原有字段，无变化）

- `cover_url` 详情（2.2.2）返回、新增（2.2.3）/编辑（2.2.4）入参，均为原有能力，本次未改动。

---

# 5 数据表说明（video 表）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| cover_url | varchar(256) 可空 | 封面图 URL（管理端列表缩略图 + 用户端封面共用） |
