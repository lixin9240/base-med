# 基层医生DR平台 · 视频分享链接模块接口文档

---

# 1 通用说明

## 1.1 基础约定

- 数据格式：请求与响应均为 `application/json`。
- 统一响应结构：

```json
{ "code": 0, "msg": "success", "data": {} }
```

- 业务失败时 `msg` 返回具体原因；下文各接口「返回示例」仅展示 `data` 部分。
- 本模块为**管理后台**接口，均需在请求头携带 `Authorization: Bearer {token}`（token 由平台登录接口获取）。
- 关联业务知识：本模块生成的链接用于发布到公众号/H5，用户通过访问链接携带的 `share` token 进入，免登录即可观看视频并答题（用户端细节见平台主接口文档 3.1 获取匿名 DR 编号）。

## 1.2 通用错误码

| HTTP 状态码 | 说明 |
| ----------- | ---- |
| 400 | 业务错误（body `code` 为 40000 段） |
| 401 | 未登录 / token 失效 |
| 404 | 资源不存在（视频不存在、无生效链接） |
| 422 | 参数错误 / 业务校验不通过 |
| 500 | 服务器错误（数据库 / 系统异常） |
| 502 | 第三方服务异常 |

> 业务失败示例：`{ "code": 30001, "msg": "视频不存在", "data": null }`。HTTP 状态码与 body `code` 按码段对应，规则同平台主接口文档。

# 2 视频分享链接接口

> 对应【视频管理】列表中「分享生成」入口。同一视频同一时刻仅一张有效分享链接；
> 生成新链接时会自动失效旧链接；链接不可多次共享编辑，需撤回后重新生成。

## 2.1 生成 / 重新生成视频分享链接

- 路径：`POST /api/admin/share-link/generate`
- 说明：为指定视频生成一张带时效的分享链接。若该视频已有生效链接（含历史过期但仍标记启用的记录），会先自动置为失效，再创建新链接并返回。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| video_id | int | 是 | 视频ID（须 ≥1） |
| expire_days | int | 是 | 链接时效天数，仅支持 1 / 3 / 5 / 7 |

### 返回示例

```json
{
    "code": 0,
    "msg": "链接生成成功",
    "data": {
        "id": 18,
        "video_id": 5,
        "url": "http://localhost:5173/mobile/quiz?videoId=5&share=wQkBx9...40位token",
        "token": "wQkBx9...",
        "expire_type": "7d",
        "expire_at": "2026-10-28 17:00:00",
        "visit_count": 0,
        "status": 1,
        "created_at": "2026-10-21 17:00:00"
    }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | int | 链接记录ID |
| video_id | int | 关联视频ID |
| url | string | 完整 H5 链接（前端域名 + `/mobile/quiz` + 查询参数 videoId、share） |
| token | string | 分享令牌（40 位随机串，作为访问凭证） |
| expire_type | string | 时效类型，存值为 `1d` / `3d` / `5d` / `7d` |
| expire_at | string | 过期时间（`Y-m-d H:i:s`），到期后自动失效 |
| visit_count | int | 访问次数（生成时为 0，随用户打开累加） |
| status | int | 链接状态：1 生效 0 已失效 |
| created_at | string | 创建时间 |

### 失败场景

- `video_id` 缺失 / 非整数 / <1 → 422「视频ID不能为空 / 必须为整数 / 不合法」
- `expire_days` 缺失 / 非整数 / 非白名单 → 422「链接时效仅支持 1/3/5/7 天」
- 视频不存在（已软删除）→ 404「视频不存在」

## 2.2 获取当前生效链接详情

- 路径：`GET /api/admin/share-link/detail`
- 说明：查询指定视频当前生效（启用且未过期）的分享链接。供列表页「分享」弹窗回填展示。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| video_id | int | 是 | 视频ID（须 ≥1） |

### 返回示例（存在生效链接）

```json
{
    "code": 0,
    "msg": "获取成功",
    "data": {
        "id": 18,
        "video_id": 5,
        "url": "https://oss.xxx.com/mobile/learn?video_id=5&share=wQkBx9...",
        "token": "wQkBx9...",
        "expire_type": "7d",
        "expire_at": "2026-10-28 17:00:00",
        "visit_count": 12,
        "status": 1,
        "created_at": "2026-10-21 17:00:00"
    }
}
```

### 返回示例（无生效链接）

```json
{
    "code": 0,
    "msg": "获取成功",
    "data": null
}
```

> 该视频不存在任何生效链接时，`data` 为 `null`，前端据此隐藏/禁用「分享」相关操作。

### 失败场景

- `video_id` 校验失败 → 422
- 视频不存在 → 404「视频不存在」

## 2.3 撤回生效链接

- 路径：`POST /api/admin/share-link/revoke`
- 说明：撤回指定视频当前生效的分享链接（置 `status=0`），撤回后该链接立即失效，用户无法再通过它访问学习页。

### 请求参数

| 参数 | 类型 | 是否必须 | 备注 |
| ---- | ---- | ---- | ---- |
| video_id | int | 是 | 视频ID（须 ≥1） |

### 返回示例

```json
{
    "code": 0,
    "msg": "撤回成功",
    "data": {
        "success": true
    }
}
```

### 失败场景

- `video_id` 校验失败 → 422
- 视频不存在 → 404「视频不存在」
- 该视频当前无生效中的链接 → 404「该视频暂无生效中的链接」

# 3 数据表说明（video_share_link）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| id | bigint | 主键 |
| video_id | int | 关联 video 表 |
| org_id | int(可空) | 机构ID（当前恒为 null） |
| token | varchar | 分享令牌 |
| expire_type | varchar | 时效类型（1d/3d/5d/7d） |
| expire_at | datetime(可空) | 过期时间 |
| visit_count | int | 访问次数 |
| status | tinyint | 1 生效 0 已失效 |
| created_by | bigint | 创建人（admin_user.id） |
| created_at / updated_at | timestamp | 创建 / 更新时间 |
| deleted_at | timestamp(可空) | 软删除时间 |
