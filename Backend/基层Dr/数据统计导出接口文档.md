# 基层医生DR平台 · 数据统计导出接口文档

> 本文档描述「数据统计」模块的**导出统计**接口（对应主接口文档 2.6.4），供前端对接使用。

---

# 1 接口概览

- 路径：`GET /api/admin/statistics/export`
- Method：GET
- 鉴权：需在请求头携带 `Authorization: Bearer {token}`（管理后台接口）
- 返回：**Excel 文件流**（`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`），文件名 `数据统计_YYYYMMDD_HHMMSS.xlsx`
- 无查询参数

> 前端对接：直接以 Blob 下载即可，无需解析响应信封。

---

# 2 导出内容（单 Sheet）

> 导出一个 Sheet「数据统计」，**单表**：第一行表头，之后每行一条视频，**末行为「合计」汇总行**。

## 2.1 表结构

| 行 | 内容 |
| ---- | ---- |
| 第 1 行 | 表头（8 列） |
| 第 2 ~ N 行 | 每一条视频对应一行 |
| 末行 | 「合计」汇总行（非视频） |

## 2.2 列说明（8 列）

| 列 | 字段来源 | 说明 |
| ---- | ---- | ---- |
| 视频 | 各视频答题情况 title | 视频标题 |
| 分类 | 各视频答题情况 category_name | 分类名，可空 |
| 状态 | 各视频答题情况 status | `已上架` / `已下架` |
| 答题次数 | 各视频答题情况 answer_times | 该视频答题记录数 |
| 平均正确率(%) | 各视频答题情况 avg_accuracy | 该视频平均正确率；无人答题为 `—` |
| 通过率(%) | 各视频答题情况 pass_rate | 该视频通过率；无人答题为 `—` |
| 最容易答错题 | 该视频错误率最高的一题题干 | 前后测合并统计；无作答数据为 `—` |
| 错误率(%) | 该题错误率 | 答错次数 / 作答次数 × 100；无数据为 `—` |

## 2.3 末行「合计」

| 列 | 值 |
| ---- | ---- |
| 视频 | `合计` |
| 答题次数 | 总答题次数（各视频之和，即大盘 answer_total_times） |
| 平均正确率(%) | **总平均正确率**（大盘 avg_accuracy） |
| 通过率(%) | **总通过率**（大盘 pass_rate） |
| 其余列 | 留空 |

## 2.4 示例（示意，非真实文件内容）

| 视频 | 分类 | 状态 | 答题次数 | 平均正确率(%) | 通过率(%) | 最容易答错题 | 错误率(%) |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 心肺复苏基础操作 | 急救技能 | 已上架 | 12 | 64 | 67 | 成人心肺复苏时，胸外按压的深度应为多少？ | 58 |
| 高血压患者的日常管理 | 慢病管理 | 已上架 | 12 | 67 | 75 | … | 45 |
| 合计 | | | 37 | 70 | 78 | | |

# 3 与页面三个接口的对应关系

| 导出列 | 对应页面接口 | 差异 |
| ---- | ---- | ---- |
| 视频 / 分类 / 状态 / 答题次数 / 平均正确率 / 通过率 | 2.6.2 video-list | 一致 |
| 最容易答错题 / 错误率 | 2.6.3 wrong-question（改） | 导出按**视频聚合**取每视频错误率最高的一题（前后测合并）；页面 2.6.3 是按题分环节的全局列表 |
| 末行「合计」的总平均正确率 / 总通过率 | 2.6.1 overview | 取自大盘 avg_accuracy / pass_rate |

---

# 4 数据表说明

| 表 | 用途 |
| ---- | ---- |
| `video` | 视频列表、分类、状态 |
| `exam_record` | 答题记录（答题次数、平均正确率、通过率、大盘指标） |
| `exam_answer` | 答题明细（每道题对错、错误率） |
| `question` | 题干（最容易答错题） |
| `system_config` | 通过线 pass_score |

---

# 5 失败场景

| 场景 | HTTP | 说明 |
| ---- | ---- | ---- |
| 未登录 / token 失效 | 401 | 前端跳登录 |
| 无任何数据 | 200 | 正常导出，仅表头 + 「合计」行 |
| 服务器 / OSS / 数据库异常 | 500 | body `code` 对应 90000 / 60000 段 |
