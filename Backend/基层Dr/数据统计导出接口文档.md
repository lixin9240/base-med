# 基层医生DR平台 · 数据统计导出接口文档

> 本文档描述「数据统计」模块的**导出统计**接口（对应主接口文档 2.6.4），供前端对接使用。

---

# 1 接口概览

- 路径：`GET /api/admin/statistics/export`
- Method：GET
- 鉴权：需在请求头携带 `Authorization: Bearer {token}`（管理后台接口）
- 返回：**Excel 文件流**（`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`），文件名 `数据统计_YYYYMMDD_HHMMSS.xlsx`（`Content-Disposition: attachment`）

> 前端对接：直接以 Blob 下载即可，无需解析响应信封。接口无查询参数。

---

# 2 导出内容（3 个 Sheet）

## 2.1 Sheet「统计大盘」

两列（指标名 / 指标值），共 6 行：

| 指标 | 说明 |
| ---- | ---- |
| 视频总数 | 全部视频数（含下架） |
| 其中已上架 | 上架视频数 |
| 答题次数 | 答题记录总数（exam_record 计数） |
| 平均正确率(%) | 所有答题记录正确率的平均值；无记录时为 `—` |
| 通过率(%) | 通过记录数 / 答题记录总数 × 100；无记录时为 `—` |
| 通过线(%) | 通过线，取自 system_config，默认 60 |

## 2.2 Sheet「各视频答题情况」

> 本表为导出主表，每行一条视频，**8 列**，末尾附一行「合计」汇总。

### 表头与字段

| 列 | 字段来源 | 说明 |
| ---- | ---- | ---- |
| 视频 | 各视频答题情况 title | 视频标题 |
| 分类 | 各视频答题情况 category_name | 分类名，可空 |
| 状态 | 各视频答题情况 status | `已上架` / `已下架` |
| 答题次数 | 各视频答题情况 answer_times | 该视频答题记录数 |
| 平均正确率(%) | 各视频答题情况 avg_accuracy | 该视频平均正确率；无人答题为 `—` |
| 通过率(%) | 各视频答题情况 pass_rate | 该视频通过率；无人答题为 `—` |
| **最容易答错题** | 该视频错误率最高的一题题干 | 前后测合并统计；无作答数据为 `—` |
| **错误率(%)** | 该题错误率 | 答错次数 / 作答次数 × 100；无数据为 `—` |

### 「合计」汇总行（末行）

| 列 | 值 |
| ---- | ---- |
| 视频 | `合计` |
| 答题次数 | 总答题次数（各视频之和，即大盘的 answer_total_times） |
| 平均正确率(%) | **总平均正确率**（大盘 avg_accuracy） |
| 通过率(%) | **总通过率**（大盘 pass_rate） |
| 其余列 | 留空 |

### 示例（示意，非真实文件内容）

| 视频 | 分类 | 状态 | 答题次数 | 平均正确率(%) | 通过率(%) | 最容易答错题 | 错误率(%) |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 心肺复苏基础操作 | 急救技能 | 已上架 | 12 | 64 | 67 | 成人心肺复苏时，胸外按压的深度应为多少？ | 58 |
| 高血压患者的日常管理 | 慢病管理 | 已上架 | 12 | 67 | 75 | … | 45 |
| 合计 | | | 37 | 70 | 78 | | |

## 2.3 Sheet「最容易答错的题」

全局按错误率从高到低，**5 列**（与页面 2.6.3 口径一致，按前测/后测分环节）：

| 列 | 字段来源 | 说明 |
| ---- | ---- | ---- |
| 题干 | wrong-question stem | 题目题干 |
| 所属视频 | wrong-question video_title | 视频标题 |
| 环节 | wrong-question stage | `前测` / `后测` |
| 作答次数 | wrong-question answer_times | 该题该环节作答次数 |
| 错误率(%) | wrong-question wrong_rate | 答错次数 / 作答次数 × 100，降序 |

# 3 与页面三个接口的对应关系

| 导出 Sheet | 对应页面接口 | 差异 |
| ---- | ---- | ---- |
| 统计大盘 | 2.6.1 overview | 一致 |
| 各视频答题情况 | 2.6.2 video-list | 导出表比页面**多两列**（最容易答错题、错误率）+ 末尾「合计」汇总行 |
| 最容易答错的题 | 2.6.3 wrong-question | 一致 |

---

# 4 数据表说明

| 表 | 用途 |
| ---- | ---- |
| `video` | 视频列表、分类、状态 |
| `exam_record` | 答题记录（答题次数、平均正确率、通过率、大盘指标） |
| `exam_answer` | 答题明细（每道题对错、错误率） |
| `question` | 题干（最容易答错题） |
| `system_config` | 通过线 pass_score |

---

# 5 失败场景

| 场景 | HTTP | 说明 |
| ---- | ---- | ---- |
| 未登录 / token 失效 | 401 | 前端跳登录 |
| 无任何数据 | 200 | 正常导出，各 Sheet 仅表头（无数据行） |
| 服务器 / OSS / 数据库异常 | 500 | body `code` 对应 90000 / 60000 段 |
