# 基层医生DR平台 · 最容易答错的题接口文档

> 本文档描述「数据统计」模块的**最容易答错的题**接口（对应主接口文档 2.6.3），供前端对接使用。

---

# 1 接口概览

- 路径：`GET /api/admin/statistics/wrong-question`
- Method：GET
- 鉴权：需在请求头携带 `Authorization: Bearer {token}`（管理后台接口，`auth:admin`）
- 无查询参数
- 返回：统一响应信封，业务数据在 `data` 字段中（数组）

## 1.1 响应信封

```json
{
  "code": 0,
  "msg": "获取成功",
  "data": [ { "...": "见下方字段说明" } ],
  "success": true,
  "trace_id": "abc123..."
}
```

> `code=0` 表示成功；前端以 `data` 为数组直接渲染列表。

---

# 2 业务语义

接口**按视频聚合**返回每个视频中错误率最高的题，而非「全部题目按错误率排序」的全局明细：

- 每个视频分别计算**前测（pretest）**与**后测（posttest）**两阶段中错误率最高的一题；
- 前后测最高的是**同一道题** → 返回**一条**（`stage=both`，作答/答错次数为前后测累计）；
- 前后测最高的**不是同一道题** → 返回**两条**（前测一条 + 后测一条）；
- 仅某一侧有作答数据时，只返回该侧一条；
- 最终结果按错误率从高到低排序（错误率相同时按作答次数降序）。

---

# 3 响应字段

`data` 为对象数组，每条记录字段如下：

| 字段         | 类型   | 说明                                                         |
| ------------ | ------ | ------------------------------------------------------------ |
| question_id  | int    | 题目 id                                                      |
| stem         | string | 题干                                                         |
| video_title  | string | 所属视频标题                                                 |
| stage        | string | 环节：`pretest` 前测 / `posttest` 后测 / `both` 前测+后测     |
| answer_times | int    | 作答次数（exam_answer 计数；`stage=both` 时为前后测累计）     |
| wrong_rate   | int    | 错误率：答错次数 / 作答次数 × 100（四舍五入，0~100）          |

---

# 4 示例

## 4.1 前后测最高不是同一道题（返回两条）

```json
{
  "code": 0,
  "msg": "获取成功",
  "success": true,
  "trace_id": "t-001",
  "data": [
    {
      "question_id": 101,
      "stem": "成人心肺复苏时，胸外按压的深度应为多少？",
      "video_title": "心肺复苏基础操作",
      "stage": "pretest",
      "answer_times": 12,
      "wrong_rate": 58
    },
    {
      "question_id": 102,
      "stem": "成人胸外按压的频率应为每分钟多少次？",
      "video_title": "心肺复苏基础操作",
      "stage": "posttest",
      "answer_times": 12,
      "wrong_rate": 42
    }
  ]
}
```

## 4.2 前后测最高是同一道题（合并为一条，stage=both）

```json
{
  "code": 0,
  "msg": "获取成功",
  "success": true,
  "trace_id": "t-002",
  "data": [
    {
      "question_id": 205,
      "stem": "胸片可以完全代替胸部 CT 用于所有肺部疾病的诊断。",
      "video_title": "胸片检查前的准备与配合",
      "stage": "both",
      "answer_times": 26,
      "wrong_rate": 54
    }
  ]
}
```

> `stage=both` 记录：`answer_times` 为前测 + 后测作答次数之和，`wrong_rate` 为合计答错次数 / 合计作答次数 × 100。

---

# 5 前端渲染建议

对应页面「最容易答错的题」表格列：所属视频 / 环节 / 题干 / 作答次数 / 错误率。

| 列       | 取值                                |
| -------- | ----------------------------------- |
| 所属视频 | `video_title`                       |
| 环节     | `stage` 映射：`pretest`→前测，`posttest`→后测，`both`→前测/后测 |
| 题干     | `stem`                              |
| 作答次数 | `answer_times`                      |
| 错误率   | `${wrong_rate}%`                    |

> **注意**：`stage=both` 需显示为「前测/后测」。请使用三值映射，不要用 `stage === 'posttest' ? '后测' : '前测'` 这类二值判断，否则 `both` 会被误显示为「前测」。

---

# 6 失败场景

| 场景                     | HTTP | 说明                                                         |
| ------------------------ | ---- | ------------------------------------------------------------ |
| 未登录 / token 失效      | 401  | 前端清 token 跳登录                                          |
| 无任何作答数据           | 200  | `data` 为空数组 `[]`，前端显示空态（如「还没有足够的作答数据」） |
| 服务器 / 数据库异常      | 500  | body `code` 对应 90000（系统）/ 60000（数据库）段            |
