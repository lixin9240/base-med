# 基层医生DR平台 · 再次答题接口文档

> 本文档描述「答题视频模块」新增的**再次答题**接口（对应平台主接口文档 3.9）。
> 供前端对接使用，含接口路径、请求/响应参数、业务规则与失败场景。

---

# 1 业务背景与流程

用户完成一遍完整学习流程后（①获取匿名 DR 编号 → ②学前答题 → ③观看视频 → ④看完答题），
若对最终正确率不满意，可在「答题结果」页点击「再答一次」，用**同一个 dr_id** 仅重答后测题目，
复用首次学前答题的结果，生成一条新的答题记录（`attempt_no` 递增），达到提高正确率的目的。

```
首次：学前答题(3.5) → 看视频(3.4) → 看完答题(3.7) → 结果页(3.8)
重答：结果页「再答一次」→ 重答后测(3.9 本接口) → 结果页(3.8)
```

再次答题与「看完答题（3.7）」的关键区别：

| 对比项 | 看完答题 3.7（submit-post） | 再次答题 3.9（retake） |
| ------ | --------------------------- | ---------------------- |
| 前置条件 | 需先完成学前答题、观看进度 ≥ 90% | 需已存在至少一条答题记录 |
| 前测结果 | 取自 `exam_pretest` 暂存，本次新评 | 复用最近一条记录的学前结果（不重新评） |
| 观看进度门槛 | 校验 | 不校验（已走过一遍） |
| 生成记录 | 生成新 `exam_record`（attempt_no 递增） | 同左，attempt_no 继续递增 |
| 通过/未通过限制 | 无 | 无（未通过、已通过均可重答提分） |

# 2 通用说明

## 2.1 基础约定

- 数据格式：请求与响应均为 `application/json`。
- 统一响应结构：

```json
{ "code": 0, "msg": "success", "data": {} }
```

- `code=0` 表示成功；业务失败时 `msg` 返回具体原因，`code` 与 HTTP 状态码按码段对应（见 2.2）。
- 本接口为**用户端公开接口**，免登录，仅凭 `dr_id` 识别用户，无需携带 `Authorization`。
- 下文「返回示例」仅展示 `data` 部分。

## 2.2 通用错误码

| HTTP 状态码 | 说明 |
| ----------- | ---- |
| 400 | 业务状态错误（body `code` 为 40000 段，如「请先完成一遍答题后再重答」） |
| 404 | 资源不存在（匿名编号不存在、视频不存在或已下架、未配置题目） |
| 422 | 参数错误 / 参数校验不通过 |

> 业务失败示例：`{ "code": 40002, "msg": "请先完成一遍答题后再重答", "data": null }`。

# 3 再次答题接口

## 3.1 提交再次答题（重答后测）

- 路径：`POST /api/public/exam/retake`
- Method：POST
- 对应页面：「答题结果」页的「再答一次」按钮 → 进入后测答题页（与看完答题同一套题目，3.6 取题）→ 提交 → 回到「答题结果」页。
- 业务规则：
  - 需该 dr_id + 视频**已存在至少一条答题记录**（即已完成一遍前测+后测），否则返回 400「请先完成一遍答题后再重答」；
  - 仅重评**后测**题目；**学前答题结果沿用最近一次答题记录**（不重新作答、不重新评分）；
  - **不再校验观看进度门槛**、**不再要求学前答题**（用户已完整走过一遍）；
  - 提交后生成一条新的 `exam_record` + 后测 `exam_answer` 明细，并将学前明细从最近一条记录复制过来（保证前后对比展示完整），`attempt_no` 继续递增；
  - 无通过/未通过限制：结果未通过或想继续提分，均可重复调用。

### 请求参数

| 参数     | 类型   | 是否必须 | 备注                                           |
| -------- | ------ | -------- | ---------------------------------------------- |
| dr_id    | string | 是       | 匿名编号（点击视频时签发，≤32 位）             |
| video_id | bigint | 是       | 视频 ID                                        |
| answers  | array  | 是       | 后测作答数组，至少 1 条，见下方 `answers` 元素说明 |

`answers` 数组元素：

| 字段        | 类型   | 是否必须 | 备注                                                         |
| ----------- | ------ | -------- | ------------------------------------------------------------ |
| question_id | bigint | 是       | 题目 ID                                                      |
| user_answer | string | 是       | 用户答案，≤32 位。判断题填 `正确`/`错误`；单选填选项键值（如 `A`）；多选按键值逗号拼接（如 `A,C`，顺序无关） |
| duration    | int    | 否       | 该题作答用时（秒），0~86400，默认 0                           |

请求示例：

```json
{
    "dr_id": "DR-2026-000017",
    "video_id": 1,
    "answers": [
        { "question_id": 101, "user_answer": "B", "duration": 12 },
        { "question_id": 102, "user_answer": "正确", "duration": 8 },
        { "question_id": 103, "user_answer": "A,C", "duration": 20 }
    ]
}
```

### 返回示例

返回结构与「3.8 获取答题结果」一致（含 `result_status` / `accuracy_rate` / `pre` / `post` / `question_detail`），前端可直接复用结果页解析逻辑：

```json
{
    "code": 0,
    "msg": "成功",
    "data": {
        "exam_record_id": 101,
        "video_id": 1,
        "video_title": "心肺复苏基础操作",
        "result_status": "pass",
        "pass_accuracy": 60,
        "accuracy_rate": 67,
        "improved_count": 1,
        "pre": { "correct": 1, "total": 3, "accuracy_rate": 33 },
        "post": { "correct": 2, "total": 3, "accuracy_rate": 67 },
        "question_detail": [
            {
                "question_id": 101,
                "type": "single",
                "stem": "成人基础生命支持中，按压与通气的比例应为？",
                "options": [
                    { "key": "A", "content": "15:2" },
                    { "key": "B", "content": "30:2" },
                    { "key": "C", "content": "5:1" },
                    { "key": "D", "content": "10:1" }
                ],
                "correct_answer": "B",
                "analysis": "成人基础生命支持推荐按压与通气比例为 30:2。",
                "pre_user_answer": "C",
                "pre_is_correct": 0,
                "post_user_answer": "B",
                "post_is_correct": 1,
                "improved": 1
            }
        ]
    }
}
```

### 字段说明

| 字段                               | 类型    | 备注                                                         |
| ---------------------------------- | ------- | ------------------------------------------------------------ |
| exam_record_id                     | bigint  | 本次重答生成的答题记录 ID，供 3.8 结果页回看用                |
| video_id                           | bigint  | 视频 ID                                                      |
| video_title                        | string  | 视频标题                                                     |
| result_status                      | string  | `pass` 通过 / `fail` 未通过，由 `accuracy_rate ≥ pass_accuracy` 判定 |
| pass_accuracy                      | int     | 通过线（百分比），默认 60，取自后台配置                      |
| accuracy_rate                      | int     | **本次后测正确率** = `post.correct / post.total × 100`（四舍五入） |
| improved_count                     | int     | 相比**首次学前答题**提升的题数（学前答错 → 本次后测答对）    |
| pre                                | object  | 学前结果（复用首次学前答题，仅作过程展示，不参与判定）        |
| pre / post.correct                 | int     | 答对题数                                                     |
| pre / post.total                   | int     | 总题数                                                       |
| pre / post.accuracy_rate           | int     | 对应环节正确率（百分比，四舍五入）                           |
| question_detail[].type             | string  | 题型：`single` 单选 / `multiple` 多选 / `judge` 判断          |
| question_detail[].stem             | string  | 题干                                                         |
| question_detail[].options          | array   | 选项列表，`{ key, content }`（判断题为空数组）               |
| question_detail[].correct_answer   | string  | 正确答案（判断题：`正确`/`错误`；多选：逗号拼接键值）         |
| question_detail[].analysis         | string  | 解析（可能为空）                                             |
| question_detail[].pre_user_answer  | string  | 首次学前答题答案                                             |
| question_detail[].pre_is_correct   | tinyint | 学前该题是否答对：0 错 1 对                                  |
| question_detail[].post_user_answer | string  | 本次后测答案                                                 |
| question_detail[].post_is_correct  | tinyint | 本次后测该题是否答对：0 错 1 对                              |
| question_detail[].improved         | tinyint | 该题是否「首次学前错 → 本次后测对」：0 否 1 是               |

> 说明：`pre_user_answer` / `pre_is_correct` 恒为**首次学前答题**的结果（多次重答时前测明细逐次复制，不改变），
> 因此 `improved` 与 `improved_count` 始终相对首次学前作答衡量，前端可直接用于「提升 N 题」的展示。

### 失败场景

| 场景 | HTTP | body code / msg |
| ---- | ---- | --------------- |
| `dr_id` 缺失 / 非字符串 / 超长 | 422 | 10001「匿名编号不能为空」 |
| `dr_id` 不存在 | 422 | 10001「匿名编号不存在」 |
| `video_id` 缺失 / 非整数 | 422 | 10001「视频ID不能为空 / 必须为整数」 |
| `video_id` 不存在 | 422 | 10001「视频不存在」 |
| 视频已下架 | 404 | 30001「视频不存在或已下架」 |
| dr_id 与 video_id 不匹配 | 422 | 10001「匿名编号与视频不匹配」 |
| 该 dr_id + 视频尚无答题记录 | 400 | 40002「请先完成一遍答题后再重答」 |
| 该视频未配置题目 | 404 | 30001「该视频尚未配置题目」 |
| answers 为空 / 缺题（少于题目总数） | 422 | 10001「答题内容不能为空」/「请先完成所有题目再提交」 |
| answers 含不属于本视频的题目 | 422 | 10001「存在不属于本视频的题目」 |
| 判断题答案非「正确/错误」 | 422 | 10001「判断题答案格式不正确」 |
| 选择题答案选项不存在 / 单选多选不符 | 422 | 10001「答案选项不存在」/「单选题只能选择一个答案」 |

# 4 数据表说明

| 表 | 说明 |
| --- | --- |
| `visit_record` | 匿名访问记录，按 `dr_id` 解析 `user_id` |
| `video` | 视频（校验上架状态 `status=1`） |
| `exam_record` | 答题记录，重答新增一行，`attempt_no` 递增，`result_status` 依本次后测正确率判定 |
| `exam_answer` | 答题明细，重答时写入后测明细（stage=posttest），并复制最近一条记录的学前明细（stage=pretest） |
| `question` / `video_question` | 题目与视频题目关联（取后测题目集合与评分） |
